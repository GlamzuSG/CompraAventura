## Instalación y ejecución
### Requisitos previos
- Node.js v18 o superior
- npm

### Pasos
```bash
git clone https://github.com/GlamzuSG/CompraAventura.git
cd CompraAventura/backend
npm install
npm start
```
La API queda disponible en http://localhost:3000
